> 三款插件 + Mac 的总介绍与完整说明：[[BrainCore LifeOS三款插件介绍、使用说明]]

BrainCore LifeOS 是一套运行在 Obsidian 中的侧边栏控制台插件。

它不是单纯的美化插件，也不是一个独立的待办工具，而是围绕 **捕捉、待办、周工作、习惯、金句、统计、归档** 构建的日常工作与知识管理中枢。

简单来说：

```text
Obsidian 是你的知识库
BrainCore LifeOS 是你的控制台
```

它的目标不是让 Obsidian 变复杂，而是让你的知识库真正开始每天持续运转。

## 一、BrainCore LifeOS 是什么

BrainCore LifeOS 是配合 Obsidian 知识库使用的侧边栏控制台。

它会把你每天最常用的操作集中到一个固定入口中，让你不需要反复翻文件夹、找模板、找入口。

你可以用它完成：

- 快速记录想法
- 快速添加待办
- 管理本周工作
- 查看每日时间进度
- 追踪习惯打卡
- 展示每日金句
- 查看知识库数据变化
- 推动任务进入归档和复盘

它更像一个日常启动面板。

你每天打开 Obsidian 后，不需要先想“我该打开哪个文件”，而是可以先进入 BrainCore LifeOS 控制台，从控制台开始当天的工作。

推荐理解方式：

```text
Inbox 负责接收
Work 负责推进
Boxes 负责存放资料
读&写负责沉淀
归档负责收束
BrainCore LifeOS 负责把这些入口连接起来
```

## 二、安装前准备

### 1. 必须安装的软件

你需要先安装：

```text
Obsidian
```

### 2. 建议安装的插件（可选增强）

BrainCore **单独就能跑**捕捉、待办、周工作、习惯、金句、Moments。下面三个是常见增强，**不是安装 BrainCore 的前置条件**：

| 插件 | 补什么 | 不装会怎样 |
|------|--------|------------|
| **Dataview** | 文件墙卡片看板（需开启 DataviewJS） | 文件墙无法渲染卡片；其它模块照常 |
| **Attachment Management** | 全库粘贴/拖入附件按扩展名分类 | BrainCore **捕捉**仍有内置四分类；其它笔记里粘贴的图不一定进 `Boxes/图片` |
| **Weread（微信读书）** | 把划线同步成库内 Markdown | 金句仍可从**随笔 callout**抽；`Weread` 目录空时会提示「开启金句轮播」 |

**配置只写一份**：安装步骤、AM 扩展名表、Weread 登录与路径对齐，全部在文末 [[#十三、推荐搭配插件]]。本章只帮你判断「要不要装」。

若已装 Dataview，请打开其设置并开启 **JavaScript Queries / DataviewJS**（**文件墙依赖它**；未开启时控制台会提示）。

### 3. 其他插件是否必须？

不必须。

最简环境：

```text
Obsidian + BrainCore LifeOS
```

QuickAdd、Templater、Tasks、Admonition 都不是依赖。

## 三、如何安装插件

下载 BrainCore LifeOS 插件压缩包后，先解压。

解压后通常会看到：

```text
main.js
manifest.json
README.md
```

其中真正影响插件运行的是：

```text
main.js
manifest.json
```

如果有 README.md，它主要是说明文档，不影响插件运行。

请把这些文件放到当前 Obsidian 库的插件目录中。

推荐目录：

```text
.obsidian/plugins/braincore-lifeos/
```

完整结构类似：

```text
你的Obsidian库/
└── .obsidian/
    └── plugins/
        └── braincore-lifeos/
            ├── main.js
            ├── manifest.json
            └── README.md
```

放好后：

```text
重启 Obsidian
→ 设置
→ 第三方插件
→ 找到 BrainCore LifeOS
→ 开启插件
```

如果看不到插件，请确认：

- 文件夹是否放在 `.obsidian/plugins/` 下面
- `main.js` 和 `manifest.json` 是否在同一级目录
- 是否已经重启 Obsidian
- 第三方插件安全模式是否已关闭

> **版本包命名**：分发常见四类——**个人版**（免激活）/ **公版（商）**（需激活）/ **公版（免激活）** / **体验版（48 小时）**。界面徽章「公版」与下载文件夹「公版（商）」通常指同一需激活公版；「个人版」同理。

## 四、如何打开控制台

插件开启后，Obsidian 左侧 Ribbon 工具栏会出现一个：

```text
☁️ 云朵图标
```

点击左侧边栏的 **☁️ 云朵图标**，即可打开 BrainCore LifeOS 控制台。

这是 BrainCore LifeOS 的日常主入口。

日常使用时，你不需要去插件设置里找入口，也不需要打开某个固定文件。只需要点击左侧工具栏的云朵图标，就可以打开控制台。

如果没有看到云朵图标，可以尝试：

```text
重启 Obsidian
→ 确认插件已开启
→ 查看左侧 Ribbon 工具栏
```

## 五、首次使用与激活

按安装包版本不同，首次进入方式略有差异：

| 版本 | 首次怎么用 |
|------|------------|
| **个人版** | 免激活，点 ☁️ 即可进入控制台 |
| **公版（商）** | 需激活码，无试用 |
| **公版（免激活）** | 无需输入激活码即可使用 |
| **体验版（48 小时）** | 侧边栏点「开启试用」开始 48 小时全功能体验，到期须激活 |

公版（商）或体验版到期后，第一次打开 BrainCore 控制台时会进入初始化引导页面。

页面中会显示：

```text
设备专属指纹
```

请按照下面步骤操作。

### 1. 复制设备指纹

复制页面中显示的设备专属指纹。

### 2. 发送给作者

将设备专属指纹发送给作者，用于生成你的专属激活码。

### 3. 输入激活码

拿到激活码后，直接在初始化页面输入激活码。

### 4. 完成激活

点击：

```text
激活
```

激活成功后即可正常进入控制台。

**公版（商）双端说明（v4.0.4+）**：激活码按设备绑定。手机、电脑请**各复制本机指纹、各激活一次**；两把码都会保存在插件设置里，随库同步后**互不覆盖**，同一台设备一般不必重复激活。

如果后续更换设备、重新安装系统或更换 Obsidian 库路径，设备指纹可能发生变化，需要重新获取激活码。

## 六、控制台七大模块总览

BrainCore LifeOS 控制台主要包含七个模块（设置里仍可单独开关 / 排序）：

```text
1. 问候语与天气
2. 时间进度
3. 快捷工具按钮
4. 待办总览
5. 习惯打卡
6. 每日金句
7. 数据统计
```

视觉上，**问候语与天气 + 年月周日进度 + 每日金句** 会合成控制台**最上方一整块**（无背景、无边框），一眼完成「今天是谁 / 时间走到哪 / 一句提醒」。下方仍是快捷按钮、待办、习惯与统计。

推荐每天打开 Obsidian 后，先点击左侧 **☁️ 云朵图标** 打开控制台，从顶部这块进入状态，再推进待办与习惯。

## 七、七大模块详细使用说明

---

## 模块一｜问候语与天气

### 功能作用

显示当前日期、时间段问候语和天气信息，并与时间进度、每日金句同处控制台最上方。

它的作用不是单纯装饰，而是给你一个轻量的启动入口。

每天打开控制台，顶部你会先看到：

- 当前日期
- 今日问候
- 天气情况
- 温度信息

### 适合场景

- 每天早上打开 Obsidian
- 开始工作前进入状态
- 查看今日天气和时间氛围

### 使用建议

建议每天第一次打开 Obsidian 时，先看一眼这个区域。

它可以帮助你从“打开软件”自然过渡到“进入今天的工作状态”。

如果天气暂时没有显示，通常是 open-meteo 接口或网络问题。控制台会**先用默认经纬度**快速显示，不会长时间停在「定位中」。可在 **设置 → 路径 → 天气定位** 检查经纬度。

---

## 模块二｜时间进度

### 功能作用

时间进度嵌在控制台最上方，展示当前时间在不同尺度下的进展：

```text
今年进度
本月进度
本周进度
今日进度
```

### 它解决什么问题？

很多时候我们不是没有计划，而是缺少对时间的感知。

这个模块可以让你直观看到：

- 今年已经过去多少
- 本月还剩多少
- 本周推进到哪一天
- 今天已经过去多少

### 适合场景

- 每天启动时看当天节奏
- 每周中段看本周进度
- 月底或年底做复盘
- 给自己一点时间压力和提醒

### 使用建议

如果你看到今日进度已经过半，但关键任务还没有开始，就可以立刻回到“待办总览”模块，选择最重要的一项开始推进。

进度条悬停可查看已过比例、剩余时间与起止区间（桌面端）。

## 模块三｜快捷工具按钮

### 功能作用

快捷工具按钮是整个插件中使用频率最高的区域。

它把高频操作集中到一个地方，让你不需要再去翻目录、找文件、找模板。

### 四个快捷按钮

控制台快捷工具区固定为四个按钮：

```text
捕捉｜文件｜Moments｜归档
```

| 按钮 | 作用 |
|------|------|
| 捕捉 | 打开捕捉面板（工作/生活/Moments/随笔/剪藏/素材/草稿七大分类） |
| 文件 | 打开文件墙（DataviewJS 卡片看板：最近上传 + 图片/PDF/音视频/附件） |
| Moments | 打开 Moments 瀑布流（顶部速记 + 按天浏览；数据在「读&写/Moments」） |
| 归档 | 归档当前或最近打开的 Markdown 中已完成的待办 |

### 使用逻辑

当你脑子里出现一个想法时：

```text
点击捕捉
→ 选择分类
→ 输入内容
→ 保存到对应位置
```

当你想快速记一条 Moments 时：

```text
点击 Moments
→ 在顶部输入框写下内容（可粘贴图片）
→ ⌘/Ctrl+Enter 或点「发布」
→ 出现在按天分组的瀑布流里
```

### Moments 完整使用说明

Moments 是 BrainCore 内置的轻记录模块，不需要再安装社区 Memoria 插件。所有记录按年份集中写入：

```text
读&写/Moments/2026.md
读&写/Moments/2025.md
```

主界面支持搜索、创建/编辑时间排序、年份/标签/类型筛选、置顶、收藏、待办、那年今日和随机抽取。顶部下载按钮集中提供 Markdown、HTML、JSON；旁边是年度全景、数据报告和侧栏切换。

添加图片时，文件统一按 BrainCore 的 Boxes 规则保存到 `Boxes/图片`，Moments 年文件只保存引用，不会创建 `Moments/attachments`。删除记录会直接从年文件里拿掉，不会生成 `_trash.md`；刚删完底部有几秒「撤销」。只有确认库内所有 Markdown 都不再引用时，才会清理对应的 Boxes 图片。

单条记录菜单中的“分享图片”提供八种主题；筛选工具区末尾的分享按钮可选择多条记录合成一张长图，并只在最底部保留一个水印。多条分享最多选择 12 条，同时受成品高度预算保护；选择器会显示当前预算，生成时提供进度和取消按钮。主题名称保持不变，其中纸张白为简洁纸张、牛皮纸为手写纸张、薄荷绿为和风纸张、木炭黑为暗色纸张。预览在弹窗中缩小显示，复制和保存仍使用原始分辨率；“纸张白”使用纯黑水印条，其余主题使用纯白水印条。复制失败时由你选择重试、保存或取消，不会自动下载。分享弹窗、Moments 主界面、年度全景和数据报告均可正常滚动，但不显示滚动条。

长笔记折叠、视图密度、内容宽度在设置 → Moments → 阅读与浏览里，改完瀑布流会立刻跟上。面板比较窄时三种宽度看起来差不多，把 Moments 拉宽后才看得出「专注 / 均衡 / 宽阔」的差别。

**智能抽选**：点「随机抽一张」时优先抽很久没打开过的记录；关掉则完全随机。
**情感色彩**：按开心、生气等关键词给卡片左边加一条明显色带，并带一层浅底。关键词会误判，所以默认关。
**Vim 快捷键**：打开 Moments 后直接按 j/k 上下选卡片，Enter 编辑，/ 搜索，i 写新记录。顶部输入框是空的时候也能用；一旦开始打字就不会抢键。默认关。

**Mac 菜单栏 App** 的「Moments」入口，以及捕捉面板里的 Moments 路由，写入同一套年文件。在 Mac 记下的内容，回到 Obsidian 打开 Moments 瀑布流即可看到；插件里发布的记录，Mac 端统计也会同步条数。

#### Mac App 写入规范（也适用于任何自己写脚本追加年文件的人）

年文件是普通 Markdown，你完全可以自己往里写，但格式必须对齐，否则插件找不到条目，编辑和删除会出问题。

```markdown
# 08月                     ← 月标题（H1），两位数月份
## 第35周                  ← ISO 周标题（H2）
### 2026-08-25 周二        ← 日标题（H3），日期 + 空格 + 周几
- 21:14                    ← 时间行，HH:mm 补零，独占一行
  和 J 聊了一小时。         ← 正文每行缩进 2 个空格
  结论：先手写两周。

---                        ← 每条记录用分隔线收口
```

**别这么写：**

- 不要写 `- 21:14 内容` 这种一行流（老格式，仍能读，但正文以 `{`、`>`、`- [ ]` 开头时会散版）。
- 不要用 Tab 或 4 空格缩进正文，也不要不缩进。
- 不要漏掉 `---`，也不要换成 `***`。
- 不要在文件里写 `# 2026`，年份由文件名承载。
- 不要把同一天的记录插到时间更晚的记录后面（同一天内按时间从早到晚排）。
- 不要整份重写年文件，只做定位追加，否则会覆盖插件刚写的内容。

**习惯打卡走的是另一条通道**：打卡数据和 Moments 设置都存在插件的 `data.json`（`.obsidian/plugins/braincore-lifeos/data.json`），不在年文件里。插件每隔几秒会比对这个文件的修改时间，Mac 端改完约 1～2 秒后只刷新打卡区。外部程序写 `data.json` 时请先读后写、保留不认识的字段。

当前版本不再提供阅读、画册和七套作品导出；需要输出单条内容时使用“分享图片”，需要汇总观察时使用“年度全景”或“数据报告”。

当你需要整理已完成任务时：

```text
点击归档
→ 将当前笔记中已勾选的待办移入归档
```

### 核心价值

快捷工具区解决的是“记录成本太高”的问题。

它的目标是让你：

```text
想到就记
有事就收
处理完再归档
```

不要一开始就追求整理完美。先捕捉，再处理，最后归档。

### 捕捉面板七大分类

点击「捕捉」后，底部七个分类**全部直接展开**，没有「⋯ 更多」这类二级菜单：

```text
桌面端：工作｜生活｜Moments｜随笔｜剪藏｜素材｜草稿（一整行）
移动端：第一行 工作｜生活｜Moments｜随笔，第二行 剪藏｜素材｜草稿
```

分类是真正的按钮，可以用 Tab 走位、Enter / 空格确认；长按（移动端）或右键（桌面端）会弹出该分类的写入位置说明。

**提交快捷键**（v4.0.0 起与套件统一）：

```text
⌘/Ctrl + Enter        发到当前高亮的分类
⌘/Ctrl + Shift + Enter 存草稿
Esc                    关闭捕捉面板
```

高亮分类会记住你上一次的选择，下次打开捕捉时默认停在那里；输入框下方的提示行会实时显示「这次 ⌘↩ 会发到哪」。内容为空时提交会有提示，不会静默失败。

| 分类 | 写入位置 / 用途 |
|------|----------------|
| 工作 | 本周工作文件 → ## 本周待办 |
| 生活 | Inbox/Tasks.md |
| Moments | 读&写/Moments（年文件，如 2026.md） |
| 随笔 | 读&写/随笔.md（年/月/周结构） |
| 剪藏 | 抓取网页 URL，保存为 Markdown |
| 素材 | 仅保存图片、文档、音视频等**文件** |
| 草稿 | Inbox/草稿.md |

#### 素材分类说明

- **仅针对文件**：只接收图片、PDF、文档、音视频等；输入框里若有额外文字则无法保存（粘贴自动生成的 `![[...]]` 除外）。
- **保存前可改名**：点「素材」后可改每个文件名。
- **存放到哪（行为摘要）**：

```text
目标四栏（与文件墙一致）
  Boxes/图片 | Boxes/PDF | Boxes/音视频 | Boxes/附件

未装 AM          → BrainCore 捕捉用内置四分类写入上表
已装 AM + 跟随开 → 捕捉与全库粘贴共用 AM 规则（推荐）
已装 AM + 跟随关 → 捕捉仍用内置四分类；其它笔记粘贴仍跟 AM
```

AM 的安装、扩展名覆盖与验收步骤见 [[#十三、推荐搭配插件]]。文件墙**只读展示**四目录，不会帮你搬家。

- **素材日志（可选）**：填标题时写入 `Boxes/素材日志.md`；留空则只存文件。

#### 剪藏说明

- 在捕捉框输入 URL，点击「剪藏」即可抓取网页正文。
- 桌面端优先提取正文；失败时降级为 Link Embed 卡片。
- 剪藏文件默认保存到 Inbox/Clippings（可在设置中修改）。

## 模块四｜待办总览

### 功能作用

待办总览模块用于聚合当前真正需要推进的任务。

它不是简单显示一个待办列表，而是把日常待办和当前周工作事项集中到一起。

### 主要读取来源

BrainCore LifeOS 的待办总览主要读取：

```text
Inbox/Tasks.md
+
当前周 Work 文件
```

### 它的意义

你每天打开控制台时，可以直接看到：

```text
这周还有哪些事情没完成
```

不需要再分别打开多个文件检查。

### 适合管理的内容

- 本周工作任务
- 临时待办事项
- 未完成事项
- 需要持续推进的项目

### 标准待办格式

建议使用 Obsidian 原生 Markdown 任务格式：

```markdown
- [ ] 这是一条未完成任务
- [x] 这是一条已完成任务
```

如果任务不显示，优先检查是否写成了标准格式。

### 使用建议

每天打开 Obsidian 后，可以按这个流程：

```text
点击 ☁️ 打开控制台
→ 查看待办总览
→ 选择今天最重要的 1-3 件事
→ 推进并勾选
```

## 模块五｜习惯打卡

### 功能作用

习惯打卡模块用于记录那些需要长期坚持的事情。

它和待办不同。

```text
待办：一次性完成的事情
习惯：需要长期重复的事情
```

### 常见习惯示例

你可以用它记录：

- 阅读
- 写作
- 运动
- 早睡
- 冥想
- 复盘
- 输出内容
- 学习英语
- 健康管理

### 它的意义

BrainCore LifeOS 不只是管理工作，也可以管理个人成长。

习惯模块可以让你看到自己是否在持续做那些“长期重要但不紧急”的事。

### 使用建议

建议把习惯打卡放在每天晚上使用。

例如：

```text
晚上收尾
→ 打开控制台
→ 完成习惯打卡
→ 简单复盘今天
```

习惯项目可以在插件配置页面中自定义，包括图标、名称、新增、删除，也可以导出或导入打卡数据。

## 模块六｜每日金句

### 功能作用

每日金句展示一句提醒或摘录，落在控制台最上方底部（与问候、时间进度同一块）。

### 内容从哪来

```text
优先：设置 → 路径 →「读书笔记」目录（默认 Weread）
补充：随笔里符合规则的 callout
抽取：笔记中「高亮划线」「读书笔记」章节（忽略内容简介、全书评论等）
```

微信读书划线需由社区插件 **Weread** 同步进库；BrainCore **只负责读取与轮播**，不负责登录微信读书。完整安装、笔记模板与路径对齐见 [[#十三、推荐搭配插件]]。

### 如何切换

- **点击** 控制台最上方（问候 / 进度 / 金句那一块）任意区域 → 立刻换下一条
- **每小时**自动换一条；尽量少重复，轮完再洗牌
- 悬停标题会提示「点击切换金句」

### 索引与更新

金句池在 `Scripts/braincore-quote-index.json`（增量索引）：

- 读书笔记 / 随笔**新增**会分批进池
- **修改**后按文件重抽；**删除**后出池
- 首次建池或笔记很多时后台追平，不堵界面

### 它的意义与使用建议

金句是轻量提醒器：唤醒旧阅读、给写作一点灵感。某句有启发时，可顺手写成随笔、Moments 或草稿。

池为空时，控制台顶部会显示「开启金句轮播」——可去设读书笔记路径，或按十三安装 Weread。

## 模块七｜数据统计

### 功能作用

数据统计模块用于展示当前知识库的核心数据变化。

它可以帮助你知道自己的知识库到底在发生什么变化，而不是只凭感觉判断。

### 当前统计维度

主要统计：

```text
📝 笔记
🖼️ 图·表
📎 附件
🏷️ 标签
⏳ 待办
📝 Moments
```

### 统计口径说明

#### 1. 笔记

统计库中独立存在的 Markdown 笔记文件。

一般指：

```text
.md 文件
```

部分特殊目录，例如模板目录，可能会被排除。

#### 2. 图·表

统计独立存在的图片、表格和画布类文件，例如：

```text
png
jpg
jpeg
gif
webp
svg
xlsx
csv
canvas
```

#### 3. 附件

统计除 Markdown、图片、表格、画布之外的其他文件，例如：

```text
pdf
doc
docx
ppt
pptx
zip
mp3
m4a
js
其他附件
```

#### 4. 标签

统计当前知识库中使用过的标签。

例如：

```text
#flash
#todo
#project
#reading
```

#### 5. 待办

待办统计主要来自：

```text
Inbox/Tasks.md
+
当前周 Work 文件中的未完成任务
```

也就是你当前真正还需要推进的任务数量。

#### 6. Moments

Moments 统计为「读&写/Moments」目录下的动态条数；点击可打开 Moments 瀑布流。原碎碎念与 Ideas 记录会在首次启动时迁入该目录。

### 今日累计说明

数据统计中可能会出现类似：

```text
↑ 3
→ 0
↓ 1
```

含义是：

```text
↑ N：今天新增后仍然存在的净增量
→ 0：今天无净变化
↓ N：今天净减少
```

**跨日说明（v4.0.5+）**：每天 0 点过后会自动按新的日历日重算；Obsidian 挂在后台过夜、第二天切回前台时也会强刷，不必重启插件。若仍看到昨天的 ↑N，点一下控制台侧栏等几秒即可；基线写在 `Scripts/braincore-stats-history.json`，一般不用手改。

### 这个模块的价值

它让你的知识库变得可以被观察。

你可以知道：

- 今天新增了多少内容
- 文件是否真的在增长
- 待办是否越来越多
- Moments 是否持续输入
- 附件和图表是否越来越多

### 使用建议

不要把统计当成压力，而是把它当作仪表盘。

你只需要偶尔看一眼，知道系统是否在正常运转。

### 刷新节奏与省电（v4.0.0）

控制台打开且可见时才会定时刷新；**侧栏收起、窗口不可见或电脑休眠时会停定时器**，重新打开后再补刷，避免后台空转耗电。

- **进度条**（年月周日）：约每 3 分钟轻量更新  
- **数据统计**：文件增删或相关笔记变动后较快更新（约 0.3 秒合并）；侧栏打开时也会定期刷统计  
- **打卡同步**：Mac App / 外部改写插件 `data.json` 后，约 **1～2 秒**内重读并只刷新打卡区；切回 Obsidian 窗口时也会立刻核对  
- **从其他 App 切回**：先保证界面可点，约 0.5 秒后轻量补刷，约 3 秒后再做全量重绘（减轻长时间离开后的「假死」感）  
- **全量重绘**：间隔更长，主要用于整体同步  

附件类文件只在「新建 / 删除 / 重命名」时驱动统计刷新（忽略单纯的同步触摸），减少 iCloud 抖动带来的无效刷新。

若切回后仍卡住半分钟以上，多半是 **Obsidian / iCloud 库本身**在索引或下载，不完全是 BrainCore；可先确认库是否在 iCloud、磁盘是否繁忙。

## 八、插件配置页面说明

BrainCore LifeOS 除了左侧控制台外，还有一个配置页面。

进入路径：

```text
设置
→ 第三方插件
→ BrainCore LifeOS
```

配置页面用于调整插件的授权、路径、Moments、天气、模块顺序、配色和打卡等内容。桌面端标题格式为 **BrainCore 配置 · 个人版 v4.1.9**（版本号在标题末尾）。

常见 Tab：

```text
路径 · Moments · 模块 · 打卡 · 数据 · 快捷指令 · 关于
```

（需激活的安装包还会多一个「授权」Tab。未激活时只开放「授权 / 数据 / 快捷指令 / 关于」。）

各 Tab 大致分工：

| Tab | 管什么 |
|-----|--------|
| 路径 | 各类内容写到库里哪个文件夹，以及天气经纬度 |
| Moments | 年文件目录、发送快捷键、移动端入口、每日目标、每页条数；折叠区里还有阅读浏览与分享水印 |
| 模块 | 控制台七个模块的开关与顺序、配色 |
| 打卡 | 习惯项目、图标、导入导出 |
| 数据 | 双存储对照表、data.json 位置 |
| 快捷指令 | iOS 快捷指令部署与 deep link 复制 |
| 关于 | 版本、作者、文档入口、已下线功能说明、LifeOS 套装 |

### 1. 授权激活

配置页面顶部通常会显示授权激活区域。

这里会展示：

```text
设备库特征指纹
```

如果插件还没有激活，可以复制这个指纹发送给作者获取激活码。

拿到激活码后，可以在这里输入激活码完成授权。

如果你已经通过控制台初始化页面完成激活，**当前这台设备**一般不需要重复操作。若手机、电脑共用同一库：另一台设备仍需用**那台设备自己的指纹**激活一次（v4.0.4+ 两把码会一并保留）。

### 2. 路径映射配置

路径映射配置决定了插件把不同类型内容写入或读取到哪里。

常见配置包括：

```text
工作存放
生活存放
Moments 存放
随笔存放
剪藏存放
草稿存放
附件存放
素材日志
文件墙
跟随 Attachment Management
读书笔记
```

这些路径会影响快捷捕捉、素材分类、金句读取、待办聚合和内容归档等功能。

字段含义（与附件 / 金句相关的几项）：

```text
附件存放
  → 未装 AM 时，内置四分类里「其余」文件的目录（默认 Boxes/附件）
跟随 Attachment Management
  → 开：已装 AM 时捕捉严格跟 AM（推荐）
  → 关：捕捉强制用内置四分类（其它笔记粘贴仍跟 AM）
文件墙
  → 打开看板的笔记路径；看板只读 Boxes 四子目录，不负责分类
素材日志
  → 素材捕捉可选备注（默认 Boxes/素材日志.md；标题留空则不写）
读书笔记
  → 金句轮播读取目录（默认 Weread）；须与 Weread 插件输出目录一致
```

其它如 Moments / 草稿 / 工作 / 剪藏：用默认库结构一般不用改；改过文件夹名时再在这里对齐。

AM、Weread 的逐步配置见 [[#十三、推荐搭配插件]]。改路径前请确认目标文件夹已存在。

---

### 3. 天气定位配置（位于 **路径** Tab 内）

天气定位配置用于设置默认经纬度。

常见字段包括：

```text
默认纬度 Latitude
默认经度 Longitude
```

打开控制台时**先用此处默认经纬度**拉取天气；若 4 小时内已有成功的网络定位（ipwho / ipinfo / geolocation-db），则优先使用该坐标。后台每 **4 小时** 最多尝试一次定位；失败则继续用默认经纬度。天气先用 open-meteo，失败自动切换 wttr.in；结果缓存 **1 小时**。

使用说明与更新日志可在激活页或设置 → 关于中手动打开。版本升级后会自动展示一次当前版本更新日志；同一版本确认后不再重复弹出。库内《BrainCore LifeOS 插件使用说明》只在初次安装或插件升级时自动生成并打开一次；你删掉或读过后，同一版本再打开 Obsidian 不会再自动生成。需要时到设置 → 关于手动打开即可。

你可以通过地图坐标拾取工具查询所在地经纬度。

例如：

```text
纬度：31.2304
经度：121.4737
```

如果你不确定怎么填写，可以暂时保持默认值。

天气拉取失败时，控制台顶部会显示「天气暂不可用 · 点此填城市坐标」，点一下就会跳到这里。

---

### 4. Moments 设置（**Moments** Tab）

v4.0.0 起，Moments 的常用开关集中在独立的 **Moments** Tab。记录本身写进年文件，设置本身存在插件的 `data.json`。

常用项：

```text
年文件目录        默认 读&写/Moments，改完立刻生效
发送快捷键        ⌘/Ctrl + Enter 发布（默认），或改成 Enter 直接发布
移动端输入入口    悬浮按钮（默认）或输入框常驻
每日目标          用于统计里的当天完成度，默认 5 条
每页条数          瀑布流一次加载多少条，默认 50
```

折叠区点标题即可展开/收起，没有三角符号。进阶项包括折叠行数、密度、内容宽度、侧栏年份、发布后清空、智能抽选、情感色彩、Vim 快捷键、启动时打开，以及分享水印（作者名、签名、头像）。头像的「从仓库选择 / 从本地/相册 / 清除」单独一行、三钮等宽。

**智能抽选**：点「随机抽一张」时优先抽很久没打开过的记录；关掉则完全随机。
**情感色彩**：按开心、生气等关键词给卡片左边加一条明显色带，并带一层浅底。关键词会误判，所以默认关。
**Vim 快捷键**：打开 Moments 后直接按 j/k 上下选卡片，Enter 编辑，/ 搜索，i 写新记录。顶部输入框是空的时候也能用；一旦开始打字就不会抢键。默认关。

删除会直接从年文件里拿掉，刚删完底部有几秒「撤销」。库里如果已经有旧的 `_trash.md`，插件不会再往里写，也不会自动删掉那个文件。

底部的「打开 Moments」按钮可以直接跳到瀑布流。

## 九、周工作系统说明

BrainCore LifeOS 一个重要特点是：

```text
完整的周工作模板系统
```

它不是简单生成一个周文件，而是围绕每周工作推进做了结构化设计。

---

### 1. 自动生成周工作文件

插件会围绕当前周自动生成周工作文件。打开控制台时若本周 Work 文件不存在会立刻创建；**Obsidian 没有退出、只是在后台时，系统时间跨过周一零点也会自动生成本周模板**（并尽量把上周未完成待办迁过来）。跨周时即便上周没有未完成待办，也会生成本周空模板。

手机系统若把 Obsidian 冻住，计时器可能要等你重新打开 App 才补建；电脑端只要进程还在，跨周就会建。

文件通常会按年份、月份、周次组织。

示例结构：

```text
Work/
└── 2026/
    └── 6月/
        ├── WK24 06月08日-06月14日.md
        ├── WK25 06月15日-06月21日.md
        └── WK26 06月22日-06月28日.md
```

### 好处

- 不用手动建周文件
- 不用手动分年份和月份
- 不用自己计算周次
- 更适合长期工作记录

---

### 2. 上周 / 本周 / 次周联动

周工作文件之间会形成连续关系：

```text
上周 ← 本周 → 次周
```

这样你可以很自然地回看过去，也可以推进到下一周。

### 使用场景

- 查看上周遗留任务
- 记录本周重点
- 提前安排下周事项
- 每周复盘时快速跳转

---

### 3. 未完成待办迁移

周工作系统会围绕未完成待办做流转设计。

简单理解：

```text
上周没做完的事
→ 会进入后续工作视野
→ 继续在本周推进
```

### 解决的问题

很多人每周都会重新写计划，但上周没完成的任务容易被遗忘。

周工作系统就是为了减少这种遗忘，让任务可以连续推进。

---

### 4. 和侧边栏待办总览联动

周工作文件不是孤立存在的。

它会和控制台中的“待办总览”模块形成联动。

你在 Work 中写下的任务，可以在控制台里被聚合看到。

这意味着：

```text
Work 是任务的结构化承载
控制台是任务的每日入口
```

---

## 十、推荐日常使用流程

---

### 1. 每天早上：启动

推荐流程：

```text
打开 Obsidian
→ 点击左侧 ☁️ 云朵图标
→ 打开 BrainCore 控制台
→ 看一眼控制台最上方（问候 / 天气 / 年月周日进度 / 金句；可点击换句）
→ 查看待办总览
→ 选择今天要推进的重点
```

目标是让你每天一打开 Obsidian，就知道今天该从哪里开始。

---

### 2. 白天工作：捕捉和推进

当你工作过程中出现想法、任务、资料时，可以这样处理：

```text
有想法
→ 用快捷捕捉记录

有任务
→ 记录到待办

有草稿
→ 放入草稿区

有资料
→ 放入 Boxes 或对应目录
```

原则是：不要一开始就追求整理完美。

先把东西收进系统，再统一处理。

---

### 3. 晚上收尾：打卡和整理

晚上可以这样使用：

```text
打开控制台
→ 勾选已完成任务
→ 完成习惯打卡
→ 处理 Inbox 中的临时内容
→ 需要归档的内容进行归档
```

目标是每天都让系统稍微变干净一点。

---

### 4. 每周复盘：查看 Work

每周结束时，可以打开当前周 Work 文件。

建议检查：

- 本周完成了什么
- 哪些任务没有完成
- 哪些任务需要延续到下周
- 本周有哪些重要记录
- 下周需要提前安排什么

推荐节奏：

```text
周日晚上
或
周一早上
```

进行一次简单周复盘即可。

## 十一、注意事项

---

### 1. Dataview 不是必须

控制台多数功能直接读写库内笔记，不依赖 Dataview。

若统计看板缺数字，再检查是否安装并开启 Dataview。没有它时，捕捉、待办、习惯仍可正常使用。

---

### 2. 请通过左侧 ☁️ 图标打开控制台

BrainCore 控制台的日常入口是：

```text
左侧 Ribbon 工具栏 → ☁️ 云朵图标
```

不要每次都去插件设置页找入口。

---

### 3. 不要随意删除核心目录

请尽量保留以下目录：

```text
Inbox
Work
Boxes
Life
读&写
归档
Scripts
```

这些目录和插件的数据统计、工作流、归档逻辑可能有关。

---

### 4. 不要随意删除统计文件

插件可能会生成：

```text
Scripts/braincore-stats-history.json
Scripts/braincore-quote-index.json
```

- `braincore-stats-history.json`：统计基线和今日累计
- `braincore-quote-index.json`：金句增量索引（读书笔记 / 随笔）

不建议随意删除。删除后会重新建基线或重建金句池（笔记多时需后台追平一会儿）。

控制台刷新与耗电策略见上文「模块七｜数据统计 → 刷新节奏与省电」。

---

### 5. iCloud / OneDrive 同步需要等待

如果你使用 iCloud、OneDrive 或其他同步工具，可能会出现短暂不同步。

常见情况：

- 电脑和手机统计数量不一致
- 文件名出现了，但内容还没下载
- 图片或附件还在等待同步

通常等待同步完成即可。

---

### 6. 插件文件不要改名

插件目录中的核心文件不要随意改名：

```text
main.js
manifest.json
```

如果改名，Obsidian 可能无法识别插件。

---

### 7. 旧脚本不是必须

BrainCore LifeOS 已经内置很多功能，例如：

- 捕捉
- Moments
- 待办
- 周工作
- 习惯
- 统计
- 归档

所以旧的 QuickAdd、Templater 捕捉脚本不是必须依赖。

可以根据实际情况逐步移除。

## 十二、常见问题

---

### Q1：为什么打开后提示 Dataview？

这是建议项，不是阻断。统计看板在未安装 Dataview 时会降级，其它模块可继续用。

若要补齐统计，请开启：

```text
设置
→ 第三方插件
→ Dataview
→ 开启
```

并确认 DataviewJS 已开启。

---

### Q1b：为什么《插件使用说明》删了又出现？

只应在 **初次安装** 或 **插件版本升级** 时自动生成并打开一次。同一版本里删掉或读过之后，再打开 Obsidian 不会自动生成。需要时到 **设置 → 关于 → 使用说明** 手动打开。

---

### Q2：为什么左侧没有 ☁️ 云朵图标？

请检查：

```text
插件是否开启
main.js 是否存在
manifest.json 是否存在
插件目录是否正确
是否重启过 Obsidian
```

如果都正确，重启 Obsidian 后一般会出现。

---

### Q2b：电脑挂着不过去控制台，跨周会建新周模板吗？

会。只要 Obsidian 进程还在（没被杀掉），系统时间过了周一零点就会自动生成本周 Work 文件，并把上周未完成待办迁过来。不必等你下次点开控制台。手机若把 App 冻在后台，可能要重新打开一次才补建。

---

### Q3：为什么待办总览没有显示？

请检查：

```text
Inbox/Tasks.md 是否存在
当前周 Work 文件是否存在
任务是否使用 - [ ] 格式
统计数字是否需要 Dataview
```

标准待办格式是：

```markdown
- [ ] 这是一条未完成任务
- [x] 这是一条已完成任务
```

---

### Q4：为什么统计数量和 Finder / 文件管理器看到的不一样？

可能原因包括：

- 文件还在同步
- 某些文件被系统隐藏
- 模板目录被排除
- iCloud 文件还未下载到本机
- Obsidian 尚未完成索引

一般等待同步完成，或重启 Obsidian 后会恢复。

---

### Q5：能不能不装 QuickAdd / Templater / Tasks？

可以。

BrainCore LifeOS 的目标就是尽量减少额外依赖。

最简环境是：

```text
Obsidian
+
BrainCore LifeOS
```

QuickAdd、Templater、Tasks 都不是必须。

---

### Q6：手机端可以用吗？

可以，但手机端首次加载可能稍慢。

如果你使用 iCloud 或其他同步方式，请确保文件已经同步到手机本地。

公版（商）在手机、电脑共用同一库时：请在两端**各激活一次**（各用本机指纹对应的激活码）。v4.0.4 起两把码会一起保存，同步后不会再互相顶掉。

---

### Q7：README.md 可以不放吗？

可以。

插件真正运行需要的是：

```text
main.js
manifest.json
```

README.md 只是说明文档，不影响插件运行。

但为了方便用户理解安装和使用，交付时建议保留。

---

### Q8：配置页面改错了怎么办？

如果只是路径、颜色、模块顺序改错，一般可以重新进入插件配置页面改回来。

如果因为路径修改导致捕捉或统计异常，建议先恢复默认路径结构，再重新打开控制台。

推荐先确认这些核心路径：

```text
Inbox
Work
Boxes
Life
读&写
归档
Scripts
```

---

### Q9：素材分类为什么保存不了？

素材分类**仅针对文件**（图片、PDF、文档、音视频等），不支持附带文字说明。

如果输入框里除了自动生成的 `![[...]]` 链接外还有其他文字，请先删除文字再点「素材」。

如需同时记录说明，请先用「素材」保存文件，再到「Moments」或「随笔」中补充文字。

---

### Q10：iOS 主屏快捷指令怎么配？

推荐只做一个入口，URL 填：

```text
obsidian://braincore?action=quick
```

**部署**：快捷指令 App → 新建 → 打开 URL → 粘贴 → 加到主屏幕。  
**使用**：点图标打开捕捉面板；也可 **设置 → 无障碍 → 触控 → 轻点背面** 绑定同一快捷指令。

链接在设置 → **快捷指令** 可复制；说明笔记可点「快捷指令使用说明」打开。

---

### Q11：装了 Attachment Management，图片怎么还是乱跑？

按顺序核对：

1. AM 已启用，根目录为 `Boxes`，扩展名覆盖指向 `图片` / `PDF` / `音视频` / `附件`
2. BrainCore → 路径 → **跟随 Attachment Management** 为开启（捕捉才跟 AM）
3. 文件墙只展示四目录里**已有**的文件；旧文件不会自动搬家
4. 完整步骤见 [[#十三、推荐搭配插件]]

---

### Q12：金句一直空，或提示「开启金句轮播」？

1. 确认「读书笔记」路径（默认 `Weread`）下已有同步出来的 `.md`
2. 笔记里需有 `## 高亮划线` 或 `## 读书笔记` 章节
3. 路径须与 Weread 插件的输出目录**完全一致**
4. 也可用随笔 callout 作为来源；详见十三 Weread 小节

## 十三、推荐搭配插件

本章是 **Dataview / Attachment Management / Weread** 的唯一完整配置说明。前面章节只讲「用起来会怎样」，具体怎么装、怎么填，以这里为准。

### 总览：谁管什么

```text
Dataview              → 查询与文件墙展示（读）
Attachment Management → 全库附件写入分类（写）
Weread                → 微信读书划线同步进库（写 Markdown）
BrainCore             → 捕捉入口、金句轮播、文件墙入口（读 + 部分写）
```

三者互不替代：AM 不管金句，Weread 不管附件，文件墙不负责把文件搬进 Boxes。

---

### 1. Dataview（统计 / 文件墙）

**装它做什么**：文件墙 DataviewJS 卡片看板（以及部分可选查询）。

**怎么开**

```text
设置 → 第三方插件 → 浏览 → 搜索 Dataview → 安装并启用
→ Dataview 设置 → 开启 JavaScript Queries / DataviewJS
```

**不装 / 未开 DataviewJS**：捕捉、待办、周工作、习惯、金句、Moments、多数统计仍可用；**文件墙不会显示卡片看板**（需 DataviewJS，并非「静默降级成别的视图」）。

---

### 2. Attachment Management（全库附件分类）

#### 为什么需要

| 场景 | 谁决定文件落到哪 |
|------|------------------|
| BrainCore 捕捉 / 素材 | 未装 AM → 内置四分类；已装且「跟随」开 → AM |
| 任意笔记里粘贴、拖入图片 | 只有 AM（或 Obsidian 默认附件路径）会管 |
| 文件墙 | **只读** `Boxes/图片|PDF|音视频|附件`，不分类、不搬家 |

目标目录（与文件墙四栏对齐）：

```text
Boxes/图片
Boxes/PDF
Boxes/音视频
Boxes/附件
```

#### 推荐配置步骤

1. 社区插件 → 浏览 → 搜索 `Attachment Management` → 安装并启用  
2. 打开 AM 设置，保存位置选「指定根目录」一类（界面可能写作 `inFolderBelow` / Root folder）  
3. 根目录填：`Boxes`  
4. 在 **Extension Override（扩展名覆盖）** 中增加（字段名以你安装的 AM 版本为准）：

| 扩展名匹配（示意） | 子目录 |
|--------------------|--------|
| `png\|jpg\|jpeg\|gif\|webp\|svg\|bmp\|heic` | `图片` |
| `pdf` | `PDF` |
| `mp3\|wav\|m4a\|mp4\|mov\|webm\|…` | `音视频` |
| 其它 / 默认 | `附件` |

5. 重启 Obsidian 或重载插件后，在**任意笔记**粘贴一张图，确认进了 `Boxes/图片`  
6. BrainCore → 设置 → **路径** → 保持 **跟随 Attachment Management** 开启  

#### 与 BrainCore 的关系（避免两套规则）

```text
未安装 AM
  → 仅捕捉走内置四分类；其它笔记粘贴走 Obsidian 默认附件路径

已安装 AM +「跟随」开启（推荐）
  → 捕捉 + 全库粘贴共用 AM，目录统一

已安装 AM +「跟随」关闭
  → 捕捉仍用内置四分类；其它笔记粘贴仍跟 AM
  → 可能出现两套落点，一般只在排障时临时关闭
```

---

### 3. Weread（微信读书 → 每日金句）

#### 为什么需要

```text
Weread 插件     → 登录微信读书，把划线同步成库内 .md
BrainCore 金句  → 读取「读书笔记」路径下的摘录并轮播
```

两边**路径必须一致**。BrainCore 默认目录名是 `Weread`；你也可以改成别的（例如 `读&写/Reading/weread`），只要 Weread 输出目录与 BrainCore「读书笔记」填同一个即可。BrainCore 不会替你登录微信读书。

社区里插件名常为 **Weread**，或带「微信读书」字样。

#### 笔记模板（重要）

Weread **要用模板**才会生成带 `## 高亮划线` / `## 读书笔记` 的笔记；金句只从这两节抽取。请把下面整段复制到：

```text
Weread 插件设置 → 笔记模板 / Template
```

仓库内完整模板文件：`docs/templates/weread-note.md`（与下方内容相同，可对照复制）。

````markdown
---
tags:
  - 读书
  - 微信读书
  - weread
isbn: {{ metaData.isbn }}
category: {{ metaData.category }}
---

> {{ metaData.intro | striptags(true) | trim }}

{% endif -%}

{%- endfor -%}
````

#### 推荐配置步骤

1. 社区插件 → 浏览 → 搜索 `Weread` → 安装并启用  
2. Weread 设置 → 登录微信读书账号  
3. 把上面的**笔记模板**整段贴进 Weread 的模板框并保存  
4. 笔记输出目录设为 **`Weread`**（或你自定义的文件夹；下一步必须填同一个）  
5. BrainCore → 设置 → **路径** → **读书笔记** 填同一路径（默认 `Weread`）  
6. 在 Weread 里执行一次同步，确认库内出现类似 `Weread/某书名.md`，且笔记里有 `## 高亮划线` 或 `## 读书笔记`  
7. 打开 BrainCore 控制台：最上方应出现金句；点击最上方那一块可切换下一条  

#### 不装 Weread 时

- 金句仍可从**随笔**里符合规则的 callout 抽取  
- 读书笔记目录为空时，会提示「开启金句轮播」→ 可点链接去设路径，或按上面安装 Weread

## 十四、iOS 快捷指令（主屏入口）

BrainCore 支持通过 `obsidian://braincore` 从 iPhone 主屏幕或背面轻点一键进入。

### 部署

在 iPhone 打开「快捷指令」App：新建→「打开 URL」→粘贴：

```text
obsidian://braincore?action=quick
```

→ 添加到主屏幕（也可在设置 → **快捷指令** 复制链接）。不必再套「打开 App」。

### 使用

- 点主屏幕图标：打开快速面板（优先显示捕捉区）  
- **轻点背面**：设置 → 无障碍 → 触控 → 轻点背面 → 选中该快捷指令  

快速面板内已有捕捉 / 最近 / Moments / 归档，多数场景一个入口就够。

（兼容：`action=tasks` 与 `quick` 相同，可忽略。）

## 十五、一句话总结

BrainCore LifeOS 是《大鹏一日同风起》Obsidian 知识库的侧边栏控制台。

它把：

```text
时间进度
快捷捕捉
待办总览
习惯打卡
每日金句
数据统计
周工作模板
插件配置
```

集中到一个固定入口中。

你每天只需要：

```text
打开 Obsidian
→ 点击左侧 ☁️ 云朵图标
→ 进入 BrainCore 控制台
→ 开始记录、推进和复盘
```

它的目标不是让 Obsidian 变复杂，而是让你的知识库真正开始每天持续运转。
