用 iOS「快捷指令」从主屏幕或背面轻点一键打开 BrainCore 快速面板（含捕捉），无需先翻找侧栏。

当前插件版本：**4.1.9**

链接（复制到「打开 URL」）：

```text
obsidian://braincore?action=quick
```

---

## 一、部署（装到主屏幕）

在 iPhone 上打开「快捷指令」App：

1. 新建快捷指令  
2. 添加操作 **打开 URL**  
3. 粘贴上面的链接  
4. （可选）名称改成「BrainCore」  
5. **分享 → 添加到主屏幕**

只需「打开 URL」，不必再套「打开 App → Obsidian」。

链接也可在 Obsidian → 设置 → BrainCore → **快捷指令** 一键复制。

---

## 二、使用

- **主屏幕图标**：点快捷指令，即可打开快速面板（优先显示捕捉区）。  
- **背面轻点**（免找图标，更快）：  
  1. iPhone **设置 → 无障碍 → 触控 → 轻点背面**  
  2. 选择 **轻点两下** 或 **轻点三下**  
  3. 选中刚建好的「BrainCore」快捷指令  

之后轻点手机背面即可唤起同一面板。

---

## 三、快速面板里有什么

面板从上到下依次是：

```text
最近文件（两个入口）
输入框 + 工具栏（放大 / 上传 / 标签 / 列表 / 时间 / 优先级 / 草稿）
七个分类按钮
待办总览
习惯打卡
```

七个分类**全部直接展开**，没有「⋯ 更多」二级菜单。移动端排两行：第一行 工作｜生活｜Moments｜随笔，第二行 剪藏｜素材｜草稿。

| 分类 | 写到哪 |
|------|--------|
| 工作 | 本周工作文件 → `## 本周待办` |
| 生活 | `Inbox/Tasks.md` |
| Moments | `读&写/Moments/YYYY.md` 年文件 |
| 随笔 | `读&写/随笔.md` |
| 剪藏 | 抓网页正文，存到 `Inbox/Clippings` |
| 素材 | 只收文件，存到 Boxes |
| 草稿 | `Inbox/草稿.md` |

分类会记住你上次选的那个，下次打开默认高亮在那里。接了外接键盘时：

```text
⌘ + Enter          发到当前高亮的分类
⌘ + Shift + Enter  存草稿
```

主屏一般只放 **一个** `quick` 入口即可。

## 四、常见问题

**要不要四个主屏幕按钮？**  
不要。一个 `quick` 入口就够。

**为什么还是会先打开 Obsidian？**  
系统必须先唤起 Obsidian；插件侧会尽快弹出面板，并优先画出捕捉区。

**`action=tasks`？**  
与 `quick` 相同，可忽略。

**在 iPhone 上写的 Moments，Mac 上看得到吗？**  
看得到。两边写的都是 `读&写/Moments/YYYY.md` 同一份年文件，等 iCloud / 同步跑完就会出现。
