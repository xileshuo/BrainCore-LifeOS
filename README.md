## 安装与上手

1. 社区插件搜索 **BrainCore LifeOS**，或用 BRAT 添加：

```text
https://github.com/xileshuo/BrainCore-LifeOS
```

2. 启用后点侧栏云图标，开启 48 小时试用
3. 到期后：复制指纹 → 小红书下单 → 粘贴激活码
4. 详细说明见插件内「使用说明」

手动安装：下载 [Latest Release](https://github.com/xileshuo/BrainCore-LifeOS/releases/latest) 到 `.obsidian/plugins/braincore-lifeos/`
