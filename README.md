# BrainCore LifeOS
Obsidian 知识库侧边栏控制台（LifeOS）——捕捉、待办、周工作、习惯、统计与知识内化。
当前公开版本：**3.2.3 · 公版（需激活）**
依赖：**Dataview**（需开启 DataviewJS）。

1. 安装并启用社区插件 **BRAT**
2. 添加 Beta 插件仓库：

```text
https://github.com/xileshuo/BrainCore-LifeOS
```

3. 启用插件；之后可在 BRAT 检查更新

当前公开分发为 **公版**：需激活码后使用全部功能。新设备请复制侧栏/设置中的设备指纹，联系作者获取激活码。已激活设备升级后一般无需重新激活。
手动安装：下载 [Latest Release](https://github.com/xileshuo/BrainCore-LifeOS/releases/latest) 中的插件文件到 `.obsidian/plugins/BrainCore LifeOS/`。

## 使用说明
BrainCore LifeOS 是一套运行在 Obsidian 中的侧边栏控制台插件。

它不是单纯的美化插件，也不是一个独立的待办工具，而是围绕 **捕捉、待办、周工作、习惯、金句、统计、归档** 构建的日常工作与知识管理中枢。

简单来说：

```text
Obsidian 是你的知识库
BrainCore LifeOS 是你的控制台
```

它的目标不是让 Obsidian 变复杂，而是让你的知识库真正开始每天持续运转。

## 一、BrainCore LifeOS 是什么

BrainCore LifeOS 是配合 Obsidian 知识库使用的侧边栏控制台。

它会把你每天最常用的操作集中到一个固定入口中，让你不需要反复翻文件夹、找模板、找入口。

你可以用它完成：

- 快速记录想法
- 快速添加待办
- 管理本周工作
- 查看每日时间进度
- 追踪习惯打卡
- 展示每日金句
- 查看知识库数据变化
- 推动任务进入归档和复盘

它更像一个日常启动面板。

你每天打开 Obsidian 后，不需要先想“我该打开哪个文件”，而是可以先进入 BrainCore LifeOS 控制台，从控制台开始当天的工作。

推荐理解方式：

```text
Inbox 负责接收
Work 负责推进
Boxes 负责存放资料
读&写负责沉淀
归档负责收束
BrainCore LifeOS 负责把这些入口连接起来
```

## 二、安装前准备

### 1. 必须安装的软件

你需要先安装：

```text
Obsidian
```

### 2. 必须安装的插件

BrainCore LifeOS 的核心依赖是：

```text
Dataview
```

这是唯一必须配合使用的插件。

### 3. 建议开启 DataviewJS

请进入：

```text
设置
→ 第三方插件
→ Dataview
→ 开启 Dataview
→ 开启 JavaScript Queries / DataviewJS
```

如果没有安装或开启 Dataview，以下功能可能无法正常显示：

- 本周待办聚合
- 标签统计
- 数据统计
- Dashboard 首页部分内容
- 周工作任务联动

### 4. 其他插件是否必须？

不必须。

BrainCore LifeOS 的目标就是尽量减少额外依赖。

最简环境是：

```text
Obsidian
+
Dataview
+
BrainCore LifeOS
```

QuickAdd、Templater、Tasks 都不是必须依赖。

## 三、如何安装插件

下载 BrainCore LifeOS 插件压缩包后，先解压。

解压后通常会看到：

```text
main.js
manifest.json
README.md
```

其中真正影响插件运行的是：

```text
main.js
manifest.json
```

如果有 README.md，它主要是说明文档，不影响插件运行。

请把这些文件放到当前 Obsidian 库的插件目录中。

推荐目录：

```text
.obsidian/plugins/BrainCore LifeOS/
```

完整结构类似：

```text
你的Obsidian库/
└── .obsidian/
    └── plugins/
        └── BrainCore LifeOS/
            ├── main.js
            ├── manifest.json
            └── README.md
```

放好后：

```text
重启 Obsidian
→ 设置
→ 第三方插件
→ 找到 BrainCore LifeOS
→ 开启插件
```

如果看不到插件，请确认：

- 文件夹是否放在 `.obsidian/plugins/` 下面
- `main.js` 和 `manifest.json` 是否在同一级目录
- 是否已经重启 Obsidian
- 第三方插件安全模式是否已关闭

## 四、如何打开控制台

插件开启后，Obsidian 左侧 Ribbon 工具栏会出现一个：

```text
☁️ 云朵图标
```

点击左侧边栏的 **☁️ 云朵图标**，即可打开 BrainCore LifeOS 控制台。

这是 BrainCore LifeOS 的日常主入口。

日常使用时，你不需要去插件设置里找入口，也不需要打开某个固定文件。只需要点击左侧工具栏的云朵图标，就可以打开控制台。

如果没有看到云朵图标，可以尝试：

```text
重启 Obsidian
→ 确认插件已开启
→ 查看左侧 Ribbon 工具栏
```

## 五、首次使用与激活

按安装包版本不同，首次进入方式略有差异：

| 版本 | 首次怎么用 |
|------|------------|
| **个人版** | 免激活，点 ☁️ 即可进入控制台 |
| **公版（商）** | 需激活码，无试用 |
| **公版（免激活）** | 无需输入激活码即可使用 |

页面中会显示：

```text
设备专属指纹
```

请按照下面步骤操作。

### 1. 复制设备指纹

复制页面中显示的设备专属指纹。

### 2. 发送给作者

将设备专属指纹发送给作者，用于生成你的专属激活码。

### 3. 输入激活码

拿到激活码后，直接在初始化页面输入激活码。

### 4. 完成激活

点击：

```text
验证并激活
```

激活成功后即可正常进入控制台。

激活成功后，当前设备会保持有效。一般情况下不需要每次重复激活。

如果后续更换设备、重新安装系统或更换 Obsidian 库路径，设备指纹可能发生变化，需要重新获取激活码。

## 六、控制台七大模块总览

BrainCore LifeOS 控制台主要包含七个模块（设置里仍可单独开关 / 排序）：

```text
1. 问候语与天气
2. 时间进度
3. 快捷工具按钮
4. 本周待办
5. 习惯打卡
6. 每日金句
7. 数据统计
```

视觉上，**问候语与天气 + 年月周日进度 + 每日金句** 会合成顶部一块沉浸式 **Hero**（无背景、无边框），一眼完成「今天是谁 / 时间走到哪 / 一句提醒」。下方仍是快捷按钮、待办、习惯与统计。

推荐每天打开 Obsidian 后，先点击左侧 **☁️ 云朵图标** 打开控制台，从 Hero 进入状态，再推进待办与习惯。

## 七、七大模块详细使用说明

## 模块一｜问候语与天气

### 功能作用

显示当前日期、时间段问候语和天气信息，并与时间进度、每日金句同处顶部 Hero。

它的作用不是单纯装饰，而是给你一个轻量的启动入口。

每天打开控制台，Hero 顶部你会先看到：

- 当前日期
- 今日问候
- 天气情况
- 温度信息

### 适合场景

- 每天早上打开 Obsidian
- 开始工作前进入状态
- 查看今日天气和时间氛围

### 使用建议

建议每天第一次打开 Obsidian 时，先看一眼这个区域。

它可以帮助你从“打开软件”自然过渡到“进入今天的工作状态”。

如果天气暂时没有显示，通常是 open-meteo 接口或网络问题。控制台会**先用默认经纬度**快速显示，不会长时间停在「定位中」。可在 **设置 → 路径 → 天气定位** 检查经纬度。

## 模块二｜时间进度

### 功能作用

时间进度嵌在顶部 Hero 中，展示当前时间在不同尺度下的进展：

```text
今年进度
本月进度
本周进度
今日进度
```

### 它解决什么问题？

很多时候我们不是没有计划，而是缺少对时间的感知。

这个模块可以让你直观看到：

- 今年已经过去多少
- 本月还剩多少
- 本周推进到哪一天
- 今天已经过去多少

### 适合场景

- 每天启动时看当天节奏
- 每周中段看本周进度
- 月底或年底做复盘
- 给自己一点时间压力和提醒

### 使用建议

如果你看到今日进度已经过半，但关键任务还没有开始，就可以立刻回到“本周待办”模块，选择最重要的一项开始推进。

进度条悬停可查看已过比例、剩余时间与起止区间（桌面端）。

## 模块三｜快捷工具按钮

### 功能作用

快捷工具按钮是整个插件中使用频率最高的区域。

它把高频操作集中到一个地方，让你不需要再去翻目录、找文件、找模板。

### 四个快捷按钮

控制台快捷工具区固定为四个按钮：

```text
捕捉｜文件｜闪念｜归档
```

| 按钮 | 作用 |
|------|------|
| 捕捉 | 打开捕捉面板（工作/生活/闪念/随笔/剪藏/素材/草稿七大分类） |
| 文件 | 打开文件墙，浏览 Boxes 中的图片/PDF/音视频/附件 |
| 闪念 | 打开闪念胶囊，按关键词智能分发到 Ideas 等位置 |
| 归档 | 归档当前或最近打开的 Markdown 中已完成的待办 |

### 使用逻辑

当你脑子里出现一个想法时：

```text
点击捕捉
→ 选择分类
→ 输入内容
→ 保存到对应位置
```

当你想快速记一条闪念时：

```text
点击闪念
→ 输入关键词或内容
→ 保存到 Ideas 等路径
```

当你需要整理已完成任务时：

```text
点击归档
→ 将当前笔记中已勾选的待办移入归档
```

### 核心价值

快捷工具区解决的是“记录成本太高”的问题。

它的目标是让你：

```text
想到就记
有事就收
处理完再归档
```

不要一开始就追求整理完美。先捕捉，再处理，最后归档。

---

### 捕捉面板七大分类

点击「捕捉」后，底部为七个分类（桌面单行；窄屏/移动端可点 **⋯ 更多** 展开其余分类）：

```text
常用：工作｜生活｜闪念
更多：随笔｜剪藏｜素材｜草稿
```

| 分类 | 写入位置 / 用途 |
|------|----------------|
| 工作 | 本周工作文件 → ## 本周待办 |
| 生活 | Inbox/Tasks.md |
| 闪念 | Inbox/Ideas.md（闪念记录） |
| 随笔 | 读&写/随笔.md（年/月/周结构） |
| 剪藏 | 抓取网页 URL，保存为 Markdown |
| 素材 | 仅保存图片、文档、音视频等**文件** |
| 草稿 | Inbox/草稿.md |

#### 素材分类说明（v2.2.13+）

- **仅针对文件**：素材分类只接收图片、PDF、文档、音视频等附件。
- **不可附带文字**：输入框中有额外文字时无法保存（粘贴/上传自动生成的 `![[...]]` 链接除外）。
- **保存前可改文件名**：点击「素材」后弹出对话框，可修改每个文件的名称。
- **自动分类存放**：
  - 已安装 **Attachment Management** 且配置了扩展名规则时，按 AM 分类（如 png→Boxes/图片、pdf→Boxes/PDF）。
  - 未安装 AM，或某类型未配置规则时，统一保存到 **Boxes/附件**。
- **素材日志（可选）**：填写标题时写入 `Boxes/素材日志.md`；留空则只保存文件。文件墙为 DataviewJS 看板，**不再写入索引**。

#### 剪藏说明

- 在捕捉框输入 URL，点击「剪藏」即可抓取网页正文。
- 桌面端优先使用 Defuddle 全文引擎；失败时降级为 Link Embed 卡片。
- 剪藏文件默认保存到 Inbox/Clippings（可在设置中修改）。

## 模块四｜本周待办

### 功能作用

本周待办模块用于聚合当前真正需要推进的任务。

它不是简单显示一个待办列表，而是把日常待办和当前周工作事项集中到一起。

### 主要读取来源

BrainCore LifeOS 的本周待办主要读取：

```text
Inbox/Tasks.md
+
当前周 Work 文件
```

### 它的意义

你每天打开控制台时，可以直接看到：

```text
这周还有哪些事情没完成
```

不需要再分别打开多个文件检查。

### 适合管理的内容

- 本周工作任务
- 临时待办事项
- 未完成事项
- 需要持续推进的项目

### 标准待办格式

建议使用 Obsidian 原生 Markdown 任务格式：

```markdown
- [ ] 这是一条未完成任务
- [x] 这是一条已完成任务
```

如果任务不显示，优先检查是否写成了标准格式。

### 使用建议

每天打开 Obsidian 后，可以按这个流程：

```text
点击 ☁️ 打开控制台
→ 查看本周待办
→ 选择今天最重要的 1-3 件事
→ 推进并勾选
```

## 模块五｜习惯打卡

### 功能作用

习惯打卡模块用于记录那些需要长期坚持的事情。

它和待办不同。

```text
待办：一次性完成的事情
习惯：需要长期重复的事情
```

### 常见习惯示例

你可以用它记录：

- 阅读
- 写作
- 运动
- 早睡
- 冥想
- 复盘
- 输出内容
- 学习英语
- 健康管理

### 它的意义

BrainCore LifeOS 不只是管理工作，也可以管理个人成长。

习惯模块可以让你看到自己是否在持续做那些“长期重要但不紧急”的事。

### 使用建议

建议把习惯打卡放在每天晚上使用。

例如：

```text
晚上收尾
→ 打开控制台
→ 完成习惯打卡
→ 简单复盘今天
```

习惯项目可以在插件配置页面中自定义，包括图标、名称、新增、删除，也可以导出或导入打卡数据。

## 模块六｜每日金句

### 功能作用

每日金句展示一句提醒、摘录或启发性内容，视觉上落在顶部 Hero 底部（与问候、时间进度同一块）。

来源可以是微信读书划线、随笔 callout，或你配置的读书笔记路径。

### 如何切换

- **点击** Hero 任意区域（问候 / 进度 / 金句）→ 立刻换下一条金句
- **每小时**仍按当日种子自动轮换（不用手动点也会换）
- 界面不再显示「轻触切换」类提示，悬停时标题会提示「点击切换金句」

### 它的意义

每日金句不是简单的装饰，也不是为了制造“鸡汤感”。

它更像一个轻量提醒器：

- 提醒你保持节奏
- 唤醒过去读过的内容
- 给写作提供灵感
- 让知识库里的旧内容重新出现

### 适合场景

- 每天第一次打开控制台
- 写作前寻找状态
- 复盘时获得提醒
- 需要一点精神提示的时候

### 使用建议

如果某一句金句对你有启发，可以顺手延伸成一条随笔、闪念或写作草稿。

这样知识库就会从“存内容”慢慢变成“产生内容”。

每日金句读取位置可以在插件配置页面中设置。如果留空，通常会按默认规则读取对应目录。建议搭配社区 **Weread（微信读书）** 插件同步划线。

## 模块七｜数据统计

### 功能作用

数据统计模块用于展示当前知识库的核心数据变化。

它可以帮助你知道自己的知识库到底在发生什么变化，而不是只凭感觉判断。

### 当前统计维度

主要统计：

```text
📝 笔记
🖼️ 图·表
📎 附件
🏷️ 标签
⏳ 待办
⚡ 闪念
```

### 统计口径说明

#### 1. 笔记

统计库中独立存在的 Markdown 笔记文件。

一般指：

```text
.md 文件
```

部分特殊目录，例如模板目录，可能会被排除。

#### 2. 图·表

统计独立存在的图片、表格和画布类文件，例如：

```text
png
jpg
jpeg
gif
webp
svg
xlsx
csv
canvas
```

#### 3. 附件

统计除 Markdown、图片、表格、画布之外的其他文件，例如：

```text
pdf
doc
docx
ppt
pptx
zip
mp3
m4a
js
其他附件
```

#### 4. 标签

统计当前知识库中使用过的标签。

例如：

```text
#flash
#todo
#project
#reading
```

#### 5. 待办

待办统计主要来自：

```text
Inbox/Tasks.md
+
当前周 Work 文件中的未完成任务
```

也就是你当前真正还需要推进的任务数量。

#### 6. 闪念

闪念统计主要用于统计你通过闪念入口或 Ideas 系统记录的内容。

### 今日累计说明

数据统计中可能会出现类似：

```text
↑ 3
→ 0
↓ 1
```

含义是：

```text
↑ N：今天新增后仍然存在的净增量
→ 0：今天无净变化
↓ N：今天净减少
```

### 这个模块的价值

它让你的知识库变得可以被观察。

你可以知道：

- 今天新增了多少内容
- 文件是否真的在增长
- 待办是否越来越多
- 闪念是否持续输入
- 附件和图表是否越来越多

### 使用建议

不要把统计当成压力，而是把它当作仪表盘。

你只需要偶尔看一眼，知道系统是否在正常运转。

## 八、插件配置页面说明

BrainCore LifeOS 除了左侧控制台外，还有一个配置页面。

进入路径：

```text
设置
→ 第三方插件
→ BrainCore LifeOS
```

配置页面用于调整插件的授权、路径、天气、模块顺序、配色和习惯打卡等内容。桌面端标题格式为 **BrainCore 配置 · 个人版 v3.2.3**（版本号在标题末尾）。

---

### 1. 授权激活

配置页面顶部通常会显示授权激活区域。

这里会展示：

```text
设备库特征指纹
```

如果插件还没有激活，可以复制这个指纹发送给作者获取激活码。

拿到激活码后，可以在这里输入激活码完成授权。

如果你已经通过控制台初始化页面完成激活，这里一般不需要重复操作。

---

### 2. 路径映射配置

路径映射配置决定了插件把不同类型内容写入或读取到哪里。

常见配置包括：

```text
工作存放
生活存放
闪念存放
随笔存放
剪藏存放
草稿存放
附件存放
素材日志
文件墙
跟随 Attachment Management
读书笔记
```

这些路径会影响快捷捕捉、素材分类、金句读取、待办聚合和内容归档等功能。

例如：

```text
闪念存放 → 决定闪念记录写入哪里
草稿存放 → 决定草稿内容写入哪里
工作存放 → 决定周工作系统读取和生成的位置
剪藏存放 → 决定网页剪藏保存位置
附件存放 → 未匹配 AM 规则时的默认附件目录（默认 Boxes/附件）
文件墙 → 打开文件墙看板的路径（纯展示，素材不会写入此文件）
素材日志 → 素材捕捉可选备注（默认 Boxes/素材日志.md；留空标题则不写）
读书笔记 → 决定每日金句优先从哪里提取内容
```

如果你使用默认库结构，通常不需要修改。

如果你自己调整过文件夹名称，就需要在这里同步修改路径。

建议不要随意改路径。修改前先确认目标文件或文件夹真实存在，避免捕捉内容写入失败或统计读取不到。

---

### 3. 天气定位配置（位于 **路径** Tab 内）

天气定位配置用于设置默认经纬度。

常见字段包括：

```text
默认纬度 Latitude
默认经度 Longitude
```

打开控制台时**先用此处默认经纬度**拉取天气；若 4 小时内已有成功的网络定位（ipwho / ipinfo / geolocation-db），则优先使用该坐标。后台每 **4 小时** 最多尝试一次定位；失败则继续用默认经纬度。天气先用 open-meteo，失败自动切换 wttr.in；结果缓存 **1 小时**。

使用说明与更新日志可在激活页或设置 → 关于 中手动打开，**启动时不会自动弹出**。

你可以通过地图坐标拾取工具查询所在地经纬度。

例如：

```text
纬度：31.2304
经度：121.4737
```

如果你不确定怎么填写，可以暂时保持默认值。

---

### 4. 模块自由组合

模块自由组合用于控制侧边栏控制台显示哪些模块，以及这些模块的排列顺序。

你可以在这里：

- 开启模块
- 关闭模块
- 拖拽调整模块顺序
- 根据自己的习惯定制控制台布局

例如，如果你暂时不想显示每日金句，可以关闭每日金句模块。

如果你更重视本周待办，可以把本周待办模块拖到更靠前的位置。

模块调整后，控制台会自动刷新或在重新打开后生效。

推荐新用户先使用默认顺序，熟悉后再调整。

---

### 5. 模板色块配置

模板色块配置用于调整周工作模板中不同区域的颜色。

常见配置包括：

```text
本周待办
本周目标
本周复盘
每日追踪
```

这些颜色会影响周工作文件中的视觉区块，让你更容易区分不同内容。

例如：

```text
本周待办：适合使用醒目的颜色
本周目标：适合使用稳定的颜色
本周复盘：适合使用柔和的颜色
每日追踪：适合使用清晰但不刺眼的颜色
```

如果你不想折腾配色，保持默认即可。

---

### 6. 习惯打卡配置

习惯打卡配置用于自定义控制台里的习惯项目。

你可以在这里：

- 修改习惯名称
- 修改习惯图标
- 新增打卡项
- 删除不需要的习惯
- 导出打卡数据
- 导入打卡数据

每个习惯通常由两个部分组成：

```text
图标
习惯名称
```

例如：

```text
📖 阅读
🏃 运动
✍️ 写作
🌙 早睡
🧘 冥想
```

如果你更换设备，或想备份自己的打卡记录，可以使用导出数据功能。

如果你重新安装插件，或迁移到另一个库，可以使用导入数据功能恢复打卡记录。

### 7. 配置页面使用建议

不要一开始就大幅修改路径，否则容易造成内容写入位置和统计读取位置不一致。

## 九、周工作系统说明

BrainCore LifeOS 一个重要特点是：

```text
完整的周工作模板系统
```

它不是简单生成一个周文件，而是围绕每周工作推进做了结构化设计。

---

### 1. 自动生成周工作文件

插件会围绕当前周自动生成周工作文件。

文件通常会按年份、月份、周次组织。

示例结构：

```text
Work/
└── 2026/
    └── 6月/
        ├── WK24 06月08日-06月14日.md
        ├── WK25 06月15日-06月21日.md
        └── WK26 06月22日-06月28日.md
```

### 好处

- 不用手动建周文件
- 不用手动分年份和月份
- 不用自己计算周次
- 更适合长期工作记录

---

### 2. 上周 / 本周 / 次周联动

周工作文件之间会形成连续关系：

```text
上周 ← 本周 → 次周
```

这样你可以很自然地回看过去，也可以推进到下一周。

### 使用场景

- 查看上周遗留任务
- 记录本周重点
- 提前安排下周事项
- 每周复盘时快速跳转

---

### 3. 未完成待办迁移

周工作系统会围绕未完成待办做流转设计。

简单理解：

```text
上周没做完的事
→ 会进入后续工作视野
→ 继续在本周推进
```

### 解决的问题

很多人每周都会重新写计划，但上周没完成的任务容易被遗忘。

周工作系统就是为了减少这种遗忘，让任务可以连续推进。

---

### 4. 和侧边栏本周待办联动

周工作文件不是孤立存在的。

它会和控制台中的“本周待办”模块形成联动。

你在 Work 中写下的任务，可以在控制台里被聚合看到。

这意味着：

```text
Work 是任务的结构化承载
控制台是任务的每日入口
```

---

## 十、推荐日常使用流程

---

### 1. 每天早上：启动

推荐流程：

```text
打开 Obsidian
→ 点击左侧 ☁️ 云朵图标
→ 打开 BrainCore 控制台
→ 看一眼顶部 Hero（问候 / 天气 / 年月周日进度 / 金句；可点击换句）
→ 查看本周待办
→ 选择今天要推进的重点
```

目标是让你每天一打开 Obsidian，就知道今天该从哪里开始。

---

### 2. 白天工作：捕捉和推进

当你工作过程中出现想法、任务、资料时，可以这样处理：

```text
有想法
→ 用快捷捕捉记录

有任务
→ 记录到待办

有草稿
→ 放入草稿区

有资料
→ 放入 Boxes 或对应目录
```

原则是：不要一开始就追求整理完美。

先把东西收进系统，再统一处理。

---

### 3. 晚上收尾：打卡和整理

晚上可以这样使用：

```text
打开控制台
→ 勾选已完成任务
→ 完成习惯打卡
→ 处理 Inbox 中的临时内容
→ 需要归档的内容进行归档
```

目标是每天都让系统稍微变干净一点。

---

### 4. 每周复盘：查看 Work

每周结束时，可以打开当前周 Work 文件。

建议检查：

- 本周完成了什么
- 哪些任务没有完成
- 哪些任务需要延续到下周
- 本周有哪些重要记录
- 下周需要提前安排什么

推荐节奏：

```text
周日晚上
或
周一早上
```

进行一次简单周复盘即可。

## 十一、注意事项

---

### 1. Dataview 必须开启

BrainCore LifeOS 很多功能都依赖 Dataview。

如果你看到控制台或 Dashboard 有内容不显示，请优先检查 Dataview 是否开启。

---

### 2. 请通过左侧 ☁️ 图标打开控制台

BrainCore 控制台的日常入口是：

```text
左侧 Ribbon 工具栏 → ☁️ 云朵图标
```

不要每次都去插件设置页找入口。

---

### 3. 不要随意删除核心目录

请尽量保留以下目录：

```text
Inbox
Work
Boxes
Life
读&写
归档
Scripts
```

这些目录和插件的数据统计、工作流、归档逻辑可能有关。

---

### 4. 不要随意删除统计文件

插件可能会生成：

```text
Scripts/braincore-stats-history.json
```

这个文件用于记录统计基线和今日累计变化。

不建议随意删除这个文件。如果删除，今日累计等统计数据可能会重新建立基线。

---

### 5. iCloud / OneDrive 同步需要等待

如果你使用 iCloud、OneDrive 或其他同步工具，可能会出现短暂不同步。

常见情况：

- 电脑和手机统计数量不一致
- 文件名出现了，但内容还没下载
- 图片或附件还在等待同步

通常等待同步完成即可。

---

### 6. 插件文件不要改名

插件目录中的核心文件不要随意改名：

```text
main.js
manifest.json
```

如果改名，Obsidian 可能无法识别插件。

---

### 7. 旧脚本不是必须

BrainCore LifeOS 已经内置很多功能，例如：

- 捕捉
- 闪念
- 待办
- 周工作
- 习惯
- 统计
- 归档

所以旧的 QuickAdd、Templater 捕捉脚本不是必须依赖。

可以根据实际情况逐步移除。

## 十二、常见问题

---

### Q1：为什么打开后提示 Dataview？

因为 Dataview 没有安装、没有开启，或者 Obsidian 还没有加载完成。

处理方式：

```text
设置
→ 第三方插件
→ Dataview
→ 开启
```

并确认 DataviewJS 已开启。

---

### Q2：为什么左侧没有 ☁️ 云朵图标？

请检查：

```text
插件是否开启
main.js 是否存在
manifest.json 是否存在
插件目录是否正确
是否重启过 Obsidian
```

如果都正确，重启 Obsidian 后一般会出现。

---

### Q3：为什么本周待办没有显示？

请检查：

```text
Inbox/Tasks.md 是否存在
当前周 Work 文件是否存在
任务是否使用 - [ ] 格式
Dataview 是否开启
```

标准待办格式是：

```markdown
- [ ] 这是一条未完成任务
- [x] 这是一条已完成任务
```

---

### Q4：为什么统计数量和 Finder / 文件管理器看到的不一样？

可能原因包括：

- 文件还在同步
- 某些文件被系统隐藏
- 模板目录被排除
- iCloud 文件还未下载到本机
- Obsidian 尚未完成索引

一般等待同步完成，或重启 Obsidian 后会恢复。

---

### Q5：能不能不装 QuickAdd / Templater / Tasks？

可以。

BrainCore LifeOS 的目标就是尽量减少额外依赖。

最简环境是：

```text
Obsidian
+
Dataview
+
BrainCore LifeOS
```

QuickAdd、Templater、Tasks 都不是必须。

---

### Q6：手机端可以用吗？

可以，但手机端首次加载可能稍慢。

如果你使用 iCloud 或其他同步方式，请确保文件已经同步到手机本地。

---

### Q7：README.md 可以不放吗？

可以。

插件真正运行需要的是：

```text
main.js
manifest.json
```

README.md 只是说明文档，不影响插件运行。

但为了方便用户理解安装和使用，交付时建议保留。

---

### Q8：配置页面改错了怎么办？

如果只是路径、颜色、模块顺序改错，一般可以重新进入插件配置页面改回来。

如果因为路径修改导致捕捉或统计异常，建议先恢复默认路径结构，再重新打开控制台。

推荐先确认这些核心路径：

```text
Inbox
Work
Boxes
Life
读&写
归档
Scripts
```

## 十四、iOS 快捷指令（主屏入口）

BrainCore 支持通过 `obsidian://braincore` 协议从 iOS 主屏幕一键进入。

### 推荐做法

主屏 **只留一个** 图标，打开 **BrainCore 快速面板**（与控制台四键同屏的轻量入口）。

### 配置步骤

1. 打开 iOS「快捷指令」App，新建快捷指令  
2. 添加操作：**打开 URL**  
3. URL 填入：`obsidian://braincore?action=quick`（可在插件设置 → 关于中复制）  
4. 将快捷指令添加到主屏幕，命名如「BrainCore」  

无需「打开 App → Obsidian」；系统会通过 URL 唤起 Obsidian。

### 可选独立动作

若你确实需要单独图标，可另建快捷指令并改 `action=`：

| action | 作用 |
|--------|------|
| `quick`（默认） | 快速面板 |
| `capture` | 捕捉 |
| `capsule` / `voice` / `mic` | 闪念胶囊 |
| `recent` / `file-wall` | 最近 / 文件墙 |
| `archive` | 归档待办 |
| `open` | 打开控制台侧栏 |
| `tasks` | 同快速面板 |

多数场景一个 `quick` 入口就够。
