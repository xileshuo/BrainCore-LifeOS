## 安装与上手

1. 设置 → 第三方插件 → 浏览 → 搜索 **BrainCore LifeOS** → 安装并启用
2. 点侧栏云图标，开启 48 小时试用
3. 试用满意后：复制指纹 → 小红书下单 → 粘贴激活码
4. 详细说明见插件内「使用说明」

### 其他安装方式
